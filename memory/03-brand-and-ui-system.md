# Brand And UI System

## Source

Brand tokens were extracted from Cultivate DOCX source styles in `M:\Cultivate\docs\source`.

## Type

- Display: Georgia.
- Body: Calibri with system fallbacks.

## Colors

| Token | Value | Use |
|---|---|---|
| Deep teal | `#2A7D6F` | Primary brand, headings, strong actions |
| Clay | `#C4622D` | Warm accent and highlights |
| Soft mint | `#E8F5F2` | Panels and calm surfaces |
| Warm cream | `#FDF6F0` | Page background and warm sections |
| Garden green | `#E8F5E9` | Outdoor/growth surfaces |
| Ink | `#243A34` | Primary text |

## UI Rules

- Use warm, grounded, calm layouts.
- Prefer full-width sections over nested cards.
- Keep cards for repeated items and lab artifacts.
- Avoid public commitment language.
- Keep owner preview polished but clearly private.
- Presentation surfaces may use larger type and focused panels, but still need clear private/internal framing.
- Dense navigation should wrap cleanly rather than hiding required private-preview routes.
